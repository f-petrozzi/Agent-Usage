# Design companion

From the repository root, run:

```bash
python3 -m http.server 4444 --bind 127.0.0.1 --directory preview
```

Open http://localhost:4444. This sample-data browser representation makes no
account requests. Keep it aligned with windows/AgentUsageFrame.cs; native DPI,
focus, and fullscreen behavior require Windows testing.

Compact hover reveals controls and reset time. Banked reset dates tween open
inline. Motion respects browser accessibility settings.
