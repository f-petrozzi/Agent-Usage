# App icon

Concept 2c LLM spark: a white four-point intelligence spark within a mint-to-yellow
ring on a dark rounded tile. Recreated as vectors from the selected preview in
`/mnt/ssd/homelab/preview-icons/concept_2c_llm_spark.jpg`.

Sources: `../../desktop/resources/icon.svg` and `icon-small.svg`. The small
variant uses a thicker ring and omits glow and rim detail for legibility at
16–32 px. The tile occupies 97% of the canvas with transparent rounded corners.

Both ICOs contain individually rendered 16, 20, 24, 32, 40, 48, 64, 96, 128 and
256 px PNG entries. The documentation PNGs are 1024 px renders. Regenerate with:

    PLAYWRIGHT_MODULE=/path/to/playwright node scripts/build-icons.cjs /tmp/spark-icons
