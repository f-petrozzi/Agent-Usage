# App icon

with the small white arc it spins while an agent works. The sources are
`../../desktop/resources/icon.svg` and `icon-small.svg` (drawn for 32 px and
below). `../../docs/agent-usage.png` and `agent-usage.png` are 1024 px renders;
`agent-usage.ico` matches `desktop/resources/icon.ico` (16 to 256 px, PNG entries).
